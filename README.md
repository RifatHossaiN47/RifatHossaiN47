## 🚀 About Me

I am a passionate **Software Engineer** and **AI/NLP Researcher** pursuing Computer Science & Engineering at **Chittagong University of Engineering and Technology (CUET)**. 

I bridge the gap between **rigorous academic research** and **scalable production software**. My work spans from architecting real-time mobile transit platforms with background IoT telemetry to publishing peer-reviewed deep learning models in **IEEE conferences**.

- 🔭 **Current Focus:** Real-time distributed systems, cross-platform mobile apps (React Native/Expo), and full-stack modern web architectures (Next.js 16, React 19).
- 🔬 **Research Interests:** Natural Language Processing (Bangla NLP), Multimodal Deep Learning, and Explainable AI (XAI with Grad-CAM).
- 🏆 **Publications:** Multiple first-author papers accepted and published in **IEEE Xplore** (SPICSCON 2025) and Springer Nature proceedings.
- 🎯 **Engineering Philosophy:** Write clean, modular, and maintainable code that solves real-world human problems with measurable impact.
